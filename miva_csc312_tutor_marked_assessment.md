## Objective

Create a simple Flask web application that includes the following components:

### Tasks & Requirements

1. **Setup**

   * Install Flask.

   * Create an `app.py` file and initialise Flask in this file.

2. **Homepage**

   * Design a basic homepage (`index.html`) using HTML and Bootstrap.

   * Place this HTML file in the `templates` folder.

3. **Signup Page**

   * Create a signup page (`signup.html`) with a form for `username` and `password` input.

   * Validate the form data using `request.form`.

4. **Database Integration**

   * Set up a MySQL database with a table named `tbl_user` to store user information (`username` and `password`).

   * Connect the Flask application to the MySQL database.

5. **Password Security**

   * Implement password hashing before storing user credentials in the database.
